# Contributing

Do not push or merge to `master` unless the owner asks.

Each desanya.tech change gets its own branch off the latest `master`, then one pull request into `master`. Work on one change at a time, and keep one pull request open at a time, unless the owner says otherwise. Leave the pull request open until the owner approves it.

The pull request description should say, in plain language, what changed and why. For a visible site change, include before and after screenshots at desktop (1280px) and phone (390px), with the changed part scrolled into view.
